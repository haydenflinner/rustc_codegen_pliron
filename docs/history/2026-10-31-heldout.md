# Held-out runtime: 1.57x on real programs we never tuned on

## Why

The card's SPD axis (0.918, rating 106) comes from the 19 criterion kernels
in `bench/benches` and their wasm twins. Every runtime change since
2026-10-12 was measured, bisected and accepted on those kernels, so their
geomean says how well we do on code shapes we have worked on, not how fast
generated code is in general. The question "are we faster than LLVM?" needs
programs nobody here has looked at.

## The suite

`bench/heldout/run.py` builds sightglass's Rust benchmarks (the Bytecode
Alliance's Wasmtime/Cranelift suite, checked out in
`../are-we-fast-yet/sightglass/benchmarks`) natively, twice:

- Each reads a fixed input from its directory, runs between
  `bench::start()` and `bench::end()`, and prints a result that is
  compared with `benchmark.stdout.expected`.
- `sightglass-api` is patched to `bench/heldout/sightglass-api`, which
  times the region with `Instant` (the real crate imports the timer from
  the sightglass wasm host).
- cargo's default release profile for both sides (opt-level 3, 16 CGUs, no
  LTO). pliron compiles the whole crate graph; std is the prebuilt stock
  one, as in `bench/run.sh`.
- LLVM and pliron runs alternate for N rounds, order flipped each round;
  per-side medians.

Left out: tract-onnx (wasi-nn), hex-simd (wasm SIMD hot path), rust-wat and
rust-wasmprinter (wasm components: wit-bindgen imports, no native build).
blind-sig's lockfile pins a proc-macro2 that no longer builds on
nightly-2026-10-22, so the copy runs `cargo update -p proc-macro2`.

## Result

`59589ee`, aarch64-apple-darwin, load 6-8, 11 rounds:

| program | what it does | LLVM | pliron | ratio | spread (L/P) |
|---|---|---|---|---|---|
| blake3-scalar | BLAKE3 hash, portable Rust | 4.13 ms | 13.00 ms | 3.149 | 3% / 3% |
| blind-sig | RSA blind signatures (bignum) | 1.87 ms | 4.02 ms | 2.148 | 4% / 4% |
| pulldown-cmark | Markdown to HTML | 5.38 ms | 8.24 ms | 1.531 | 12% / 9% |
| rust-compression | flate2 gzip round trip | 3.36 ms | 4.90 ms | 1.457 | 21% / 22% |
| rust-html-rewriter | lol_html rewriting | 7.00 ms | 10.07 ms | 1.438 | 6% / 9% |
| regex | regex crate searches | 3.89 ms | 5.12 ms | 1.315 | 11% / 14% |
| rust-json | serde_json parse + serialize | 4.58 ms | 5.87 ms | 1.282 | 24% / 9% |
| rust-protobuf | prost decode + encode | 8.68 ms | 8.68 ms | 0.999 | 11% / 16% |

Geomean **1.568** (medians; 1.56 on per-side minimums). The spreads are
far below the gaps except for protobuf, which is a tie.

The kernels on the same tip: native geomean about 0.91.

## Reading

- The kernel suite overstates us by roughly 1.7x. None of these programs
  is exotic: hashing, bignum, parsing, compression, serde.
- blake3-scalar and blind-sig are small hot loops (compression rounds,
  multi-precision multiply) and the obvious first profiles; whatever they
  show is likely to recur across the others.
- This is one machine (Apple Silicon) and short runs (2-13 ms each). It
  is enough to rank, not to quote a third digit.
