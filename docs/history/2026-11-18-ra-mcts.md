## What transfers (≤15 lines)

1. **Root Gumbel** — sample once per root action; rank `g + ln(prior)`; LCG already in-file.
2. **Sequential halving** — equal force-visits then drop half by `g+logit+σ(q̂)`; deferred once top-M caps fan-out.
3. **PUCT below root** — `Q + c·P·√N/(1+n)` so the hand prior steers after ply 0.
4. **Prior shaping** — tourn's length/cut/pass → RA: reuse used preg, penalize new preg + spill, FixedReg pin.
5. **`max_considered`** — top-M free pregs + spill (`PLIRON_RA_MCTS_TOPM`, default 8).
6. **Not transferred** — NN leaf eval, leaf batching, v_mix, training π′ (no burn / no_std); rollout stays first-fit+ε.

## Measure: before / after thoughts

**Kept:** reward = `−(distinct_preg_count + 8·spills)`. It is exactly what
`tools/raproof` prints as `preg_pressure` and what proof certificates
argue about — so MCTS and the oracle speak one language. Triangle unit
test: K3 first-fit footprint 3, MCTS ≤ that via `preg_count`.

**Limits:** regcount ignores move/reload cost, callee-save pressure, and
edit temps greedy inserts after colouring. A win on this measure can
still lose held-out cycles; treat MCTS as a *home* search that feeds
greedy edits, not a full RA replacement. Next measure upgrade (not
done): add a cheap spill-weight or move-affinity term once pins/clobbers
flow into `pins`.
