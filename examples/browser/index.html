rustc → wasm, running in your browser

rustc itself is compiled to wasm by the pliron backend; it compiles this crate to wasm with the same backend and links it with pliron-wasm-ld. A crate with fn main is built against std for wasm32-wasip1 and run on WASI; a #![no_std] crate without main targets wasm32-unknown-unknown, its zero-argument extern "C" exports are called, and print(ptr, len) writes to the output.
